# Threat-Scope

Single-page Cybersecurity Threat Tracker Dashboard built with React, Vite, Tailwind CSS, Recharts, and Lucide icons.

## Features

- Live client-side fetch from CISA KEV JSON feed
- Dark SOC-style dashboard UI
- Metric cards for total, critical, and high alerts
- Vendor breakdown doughnut chart
- Live searchable threat feed table
- Click-through detail modal with remediation link
- Loading, empty, and API error handling states

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run test
npm run build
```
